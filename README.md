# 音符盒调音台 · Music Box

适用于 **Minecraft Java 26.3 + Fabric Loader 0.19.5 + Java 25**。服务端、客户端均安装同一个 `musicbox-1.1.0.jar`，并安装 Fabric API 0.160.7 或更新的 26.3 版本。

## 使用

1. 放置原版 **音符盒（Note Block）**，右键打开金棕色调音台，无需另行合成方块。
2. 左边下拉菜单保留全部27种原版音色，统一“原版-”前缀，并增加钢琴、手风琴、竖笛、小号、唢呐、小提琴、萨克斯、架子鼓。菜单支持分页与滚轮。
3. 原版音色滑条保留 **原版音高0～24**；新增音色使用 **C3～C5（MIDI 48～72）**。原版头颅音效保持原版固定音高。松开滑条试听；也可点“试听”。
4. 点“保存”，服务器确认保存后关闭窗口。取消或 Esc 放弃草稿。
5. 用红石上升沿或生存模式轻敲触发演奏。普通乐器上方需留空，原版头颅遵循原版例外。

预听只发给当前操作者，其他玩家听不到，也不会修改已保存的声音。正式演奏沿用原版音符盒的 `RECORDS` 声音分类、音量参数 `3.0` 和距离衰减逻辑；在默认音频配置下传播范围约 48 格。所有附近玩家都能听到，受各自“唱片机／音符盒”音量设置影响。

Tab 可切换控件；滑条聚焦时左右方向键按半音调整；下拉菜单中上下方向键选择，Enter 确认，Esc 收起。Shift + 右键可保留原版放置方块行为。

## 数据与兼容性

- 没有保存过自定义配置的音符盒继续按原版规则发声。
- “原版-自动”保留原版根据底部方块／上方头颅决定音色的规则；打开未配置过的音符盒时读取其原有音高。手动指定音色时使用所选音色。
- 1.0.0已保存的八种新增音色及音高保持不变。升级需同时更新客户端与服务端。
- 配置按世界、维度、坐标保存于 `<世界目录>/data/musicbox.json`，保存采用临时文件替换；损坏文件不会被自动覆盖。
- 方块被拆除、替换或被活塞移走时清除原坐标配置；移动后的音符盒需要重新调音。掉落物不携带配置。
- 客户端必须装模组才能打开界面及听到新增音色。单装服务端无法向原版客户端提供此界面。
- 服务器校验编辑会话、交互距离、方块类型、模式及原版交互权限。第三方领地插件需自行进行兼容验证。
- 八种声音由程序合成，不是真实乐器录音；架子鼓是底鼓、嗵鼓、军鼓、踩镲的混合打击音。

## 构建与验证

在本机安装 Java 25 和 Minecraft 26.3 后运行：

```powershell
python build.py
python tests/run_tests.py
```

也可明确指定路径：

```powershell
python build.py --java-home "C:\path\to\jdk25" --minecraft-home "C:\path\to\.minecraft"
```

输出：`build/libs/musicbox-1.1.0.jar`。Minecraft 26.3 不再混淆类名，直接构建无需 remap。项目另含 Loom 1.18.2 / Gradle 9.7 配置；直接构建脚本为已验证路径。

重新生成音频需要 Python、NumPy、SoundFile：

```powershell
python tools/generate_sounds.py
python tools/generate_sounds.py --verify-only
```

音频生成脚本与全部合成音源均包含于源码中。
